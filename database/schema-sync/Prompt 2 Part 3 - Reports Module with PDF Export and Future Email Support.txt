Title: Water Company Reports Module with PDF Export and Future Email Support

We need to add a complete Reports module to the Water Company app.

The goal is to give the owner full visibility into sales, payments, production, inventory, raw materials, deliveries, expenses, losses, cash flow, customer balances, daily closing, and business performance.

Each report should support:

* Date range filter
* Relevant entity filters
* On-screen preview
* Summary totals
* Detailed table
* Export to PDF
* Consistent currency formatting based on company setup
* Future support for emailing reports to the owner

Do not implement full email sending unless email infrastructure already exists. However, structure the report generation so that emailing any report later will be straightforward.

---

## 1. Reports Page UI

Create a Reports page with report cards grouped by category.

Suggested groups:

Financial Reports:

* Daily Business Summary
* Profit and Loss
* Cash Flow
* Expense Report
* Closing Report

Sales and Customers:

* Sales Report
* Payments Received
* Customer Balances
* Customer Sales History

Production and Inventory:

* Production Report
* Raw Material Usage
* Raw Material Purchases
* Inventory / Stock
* Stock Movement
* Product Performance

Delivery and Operations:

* Delivery Run Report
* Driver Accountability
* Route Performance
* Vehicle Usage
* Loss Report

Each report card should have:

* Report name
* Short description
* View Report button

Inside each report page:

* Filters at the top
* Summary cards
* Data table
* Export PDF button
* Future Email Report button placeholder, disabled or marked “Coming soon” if email is not ready

---

## 2. PDF Export Requirements

Each report should have an `Export PDF` button.

The PDF should include:

* Company name
* Report title
* Date range
* Generated date/time
* Generated by
* Filters used
* Summary totals
* Detailed table
* Page numbers if multi-page
* Consistent currency formatting based on company setup

The PDF should be clean, readable, and suitable to send to the business owner.

---

## 3. Future Email Support Structure

Design report generation so that later we can email any report to the owner.

Add backend structure or placeholders where practical:

* ReportType
* Filters
* GeneratedBy
* GeneratedAt
* PDF file/path/blob reference if applicable
* EmailTo
* EmailStatus
* ScheduledSend support later

Do not implement full email sending unless email infrastructure already exists.
