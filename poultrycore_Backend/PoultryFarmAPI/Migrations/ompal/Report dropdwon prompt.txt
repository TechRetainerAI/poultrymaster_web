Title: Add Reports Mega Menu to Main Navigation

We already have a Reports page that groups reports into categories such as Financial, Sales & Customers, Production & Inventory, and Delivery & Operations.

We need to add Reports to the main navigation menu and make it open a mega menu showing all available reports grouped in columns.

The goal is to let users quickly see all reports from the menu and navigate directly to the report they care about without first opening the Reports page.

Required behavior:

1. Add a Reports menu item to the main navigation.

2. When the user hovers over or clicks Reports on desktop, show a wide mega menu.

3. On mobile/tablet, the mega menu should open on click/tap.

4. The mega menu should group reports in the same categories used on the Reports page.

Groups should be:

Financial:
- Daily Business Summary
- Profit & Loss
- Cash Flow
- Expense Report
- Closing Report

Sales & Customers:
- Sales Report
- Payments Received
- Customer Balances
- Customer Sales History

Production & Inventory:
- Production Report
- Raw Material Usage
- Raw Material Purchases
- Inventory / Stock
- Stock Movement
- Product Performance

Delivery & Operations:
- Delivery Run Report
- Driver Accountability
- Route Performance
- Vehicle Usage
- Loss Report
- Operational Dashboard

5. Display the groups as columns inside the mega menu.

6. Each report item should be clickable and should navigate directly to the corresponding report page.

7. Add a “View All Reports” link in the mega menu that opens the main Reports page.

8. The mega menu should close when:
- the user clicks a report,
- the user clicks outside the menu,
- the user moves away from the menu area, if using hover behavior.

9. The menu should use the same report metadata/configuration used by the Reports page so that report names and groups are not duplicated manually in two places.

10. If a new report is added later, it should be added in one report configuration list and automatically appear on both the Reports page and the Reports mega menu.

11. The mega menu should be visually clean and compact:
- category title at the top of each column,
- report names listed underneath,
- optional small description or icon if space allows,
- avoid making the menu too tall.

12. Highlight the current active report if the user is already inside a report page.

13. Respect permissions if the app has roles:
- users should only see reports they are allowed to access.

Expected final behavior:

The user can hover over or click Reports from the main menu and immediately see all reports grouped under Financial, Sales & Customers, Production & Inventory, and Delivery & Operations. The user can click any report and go directly to that report page. The main Reports page should still exist for users who prefer browsing all reports visually.
