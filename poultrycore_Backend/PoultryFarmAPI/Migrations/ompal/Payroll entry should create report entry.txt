Title: Create Linked Expense Record When Payroll Is Approved or Paid

We need payroll entries in the Water Company app to feed into the Expenses page.

Payroll is a real business cost, so once payroll is approved or marked as paid, the system should automatically create a linked Expense record.

Do not create an expense when payroll is still in Draft, Pending, or Unapproved status.

Required behavior:

1. When payroll is created as Draft or Pending, do not create an Expense record yet.

2. When payroll is Approved or Marked as Paid, create one linked Expense record for the total payroll amount.

3. The Expense record should include:
- CompanyId
- ExpenseDate = Payroll payment date or payroll approval date
- ExpenseCategory = Payroll / Salaries / Wages
- Amount = Total Payroll Amount
- PaymentMethod, if captured on payroll
- Description = Payroll for [period/date range]
- SourceType = Payroll
- SourceId = PayrollId
- CreatedBy
- CreatedAt

4. The Expenses page should show the payroll expense like other expenses.

5. The payroll expense should be clearly traceable back to the payroll record.

6. Do not create one expense per employee on the Expenses page.

7. The Payroll page should keep the employee-level payroll breakdown.

8. The Expenses page should show one summarized payroll expense for the payroll run.

9. Avoid duplicate payroll expenses.

10. If payroll is edited before approval, no expense should be created until approval/payment.

11. If an approved/paid payroll is reversed, cancelled, or reopened, the linked Expense record should also be reversed, marked inactive, or updated consistently.

12. If payroll is reapproved after correction, update or recreate the linked Expense record safely.

13. Use SourceType = Payroll and SourceId = PayrollId to find and manage the linked expense.

14. Payroll-related reports and Profit/Loss reports should include approved/paid payroll expenses.

Expected final behavior:

Payroll Draft/Pending = no expense created.

Payroll Approved/Paid = one linked payroll expense created.

Payroll Reversed/Reopened = linked expense reversed or marked inactive.

Payroll Reapproved = linked expense updated or recreated without duplicates.
